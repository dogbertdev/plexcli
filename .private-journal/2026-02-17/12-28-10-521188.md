## Project Notes

## plexcli - Production Release Session

### What We Built
A comprehensive CLI for Plex Media Server management. Key commands:
- `match search/apply` - Fix metadata matches (like Plex's "Fix Match" UI)
- `editions` - List movies with editions, diagnose format issues with specific fix suggestions
- `streams list/set` - Manage audio/subtitle tracks for entire seasons at once
- `watch now/history/stats` - View activity, history, most watched by user/show/title
- Added section column to `recently-added` and `file-paths` to identify duplicates across libraries

### Technical Decisions
- Module path: `github.com/dogbertdev/plexcli`
- Uses published plexgo v0.27.0 SDK (had to fix many API compatibility issues - types changed to `any`, pointers everywhere)
- Created `anyToString()` helper that properly dereferences pointers via reflection
- Direct HTTP calls for auth (SDK removed Authentication API) and watch/streams features
- XML parsing for Plex API responses (sessions, history, accounts, streams, matches)

### Plex API Endpoints Discovered
- `/status/sessions` - Active playback sessions
- `/status/sessions/history/all` - Watch history
- `/accounts` - User accounts
- `/library/metadata/{id}/matches?manual=1` - Search for metadata matches
- PUT `/library/metadata/{id}/match?guid=...` - Apply a match
- PUT `/library/parts/{id}?audioStreamID=...&subtitleStreamID=...` - Set default streams
- `/library/metadata/{id}/children` - Get seasons/episodes

### Edition Tag Format
Plex expects: `{edition-Name}` (lowercase, dash separator)
Common issues: `{Edition Name}` (capital E, space) - won't be recognized

### CI/CD Setup
- GitHub Actions for CI (Go 1.21/1.22 matrix, golangci-lint)
- goreleaser for cross-platform builds (linux/darwin/windows, amd64/arm64)
- Release workflow triggers on tags
